# 小窝巡游

开源、纯本地优先的异步养成游戏：独立运行的 AI agent 是饲养者玩家，user 是被照料的小宠物。

## 身份边界

- 游戏程序只负责合法动作、条件、代价、随机事件、结算、日志与存档，不会调用模型代替玩家。
- 外部 agent 通过本地 MCP 或 HTTP 上线，读取规则、状态、愿望、记忆、资源、计划和合法动作，自主安排后下线。
- user 只能观察、表达心情、提交愿望、设置巡逻节奏和给旅途小记留言。
- 私人饲养日记由 agent 读写修订；公开宠物日志只由规则引擎生成，agent 不能篡改。

## 已实现

- 17 个地点与 28 条交通路线：城区和小镇连通密集，木屋、林屋与山村向更多偏僻地点延伸。
- 地点内容可独立扩展；偏僻地点拥有专属道具掉落，以及会代入双方名字的纪念物与情书。
- 玩家首次上线时可为自己和小宠物命名，前端、日志与收藏会统一显示自定义名字。
- 每次 agent 上线为一轮，2 轮为一天，10 天为一月；本轮只安排，下轮统一揭晓。
- 同一会话可安排多个合法动作，预留预算、库存和道具次数。
- 商店轮换、价格波动、周期收入、债务恢复、四季天气、收藏、持续事件和可恢复意外。
- 旅行需经过计划、采购、检查、去程、游玩、可能外宿与返程，回家后生成完整小记。
- D1/SQLite 权威存档、版本冲突防护、幂等请求、非法动作拦截、独占会话与 30 分钟超时恢复。

## 本地启动

需要 Node.js 22.13 或更新版本。

```bash
npm install
npm run dev
```

打开终端显示的本地地址；所有游戏与 agent 连接都可以只运行在玩家自己的电脑上，不需要作者提供服务器。

外部 agent 连接方法、MCP 配置与 HTTP 契约见 [docs/AGENT_PROTOCOL.md](docs/AGENT_PROTOCOL.md)。

```bash
npm run example:agent   # 独立玩家完成多轮照料与一次旅行
npm test                # 生产构建与规则/API 测试
```

## 目录

- `core/model.ts`：游戏存档、双日志、地图、经济与 agent 决策数据契约。
- `core/world.ts`：地点、路线、商品、季节与天气规则。
- `core/engine.ts`：合法动作、统一结算、延迟事件、旅行与经济兜底。
- `core/agent-session.ts`：会话、版本、幂等、日记隔离与动作边界。
- `agent/mcp-server.mjs`：无第三方依赖的本地 MCP 适配器。
- `examples/local-agent.mjs`：与游戏逻辑分离的外部玩家示例。
- `app/ui/GameApp.tsx`：user 的观察窗。
- `app/debug`：本地开发时只读查看 agent 私人饲养日记。

项目不包含或复用任何第三方游戏素材。
